# OIROV Software Training

Training materials for the **OIROV Robotics Software Track**.

## Session 01 — Introduction to Programming

**Notebook:** [OIROV_Software_Session_01_Introduction_C_CPP.ipynb](./OIROV_Software_Session_01_Introduction_C_CPP.ipynb)

### Topics
- Programs and algorithms
- First C program
- Variables and data types
- Operators and conditions
- `for` and `while` loops
- Functions
- Arduino `setup()` and `loop()`
- First Arduino Blink sketch
- Practice tasks

### How to use
- Open the notebook in Jupyter Notebook, JupyterLab, or Google Colab to read the lesson.
- The C/C++ snippets are lesson examples; they are not Python cells to execute directly.
- Copy the Arduino Blink sketch into Arduino IDE, select the correct board and port, then upload it.
- Follow safe wiring practices. Do not power motors or pumps directly from a microcontroller output pin.
